# Design references

Interactive HTML references for the v2 design. Open them in a browser; nothing here is built or shipped.

- `Design System.dc.html`: tokens, the yellow rule, the type scale, spacing, components, accessibility and writing rules, with a light/dark toggle.
- `Portfolio v2.dc.html`: the full site prototype in EN, FR and ES, reading `content-*.js`.

The prototypes load images from `assets/`. To see them, copy `../public/assets` next to these files, or serve the repo root and open `/design/…`.

The source of truth for copy is `src/content/content.json`; the `content-*.js` files here are a snapshot from the design phase.
